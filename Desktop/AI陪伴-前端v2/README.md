# AI 克隆陪伴 · 前端

黑白灰铅笔手绘风 + 梦核治愈感回忆的 AI 陪伴应用前端。

## 设计说明

- **主界面（聊天列表、角色档案、设置等）**：黑白灰 + 手绘线条风格，象征「虚拟的、想象的」聊天世界。
- **我们的世界（回忆卡片）**：彩色梦核治愈风，象征真实发生过的回忆。

## 界面结构

| 界面       | 路径                    | 说明 |
|------------|-------------------------|------|
| 聊天列表   | `/`                     | 入口，右上角可添加角色 |
| 添加角色   | `/add-character`        | 上传聊天记录 AI 克隆 / 手动填写参数创建 |
| 角色档案   | `/character/:id`        | 从聊天框右上角进入，展示档案、我们的关系、我们的世界入口 |
| 我们的世界 | `/character/:id/world`  | 彩色回忆卡片列表 |
| 聊天详情   | `/chat/:id`             | 与某角色对话，右上角进入档案 |
| 设置       | `/settings`             | 关于、偏好、数据 |

## 运行

```bash
npm install
npm run dev
```

构建：`npm run build`，预览：`npm run preview`。

## 技术栈

- Vue 3 + Vue Router
- Vite
- 纯 CSS 手绘风（无 UI 库）
